Figure X. Core gene identification across prevalence thresholds in E. faecalis.

(A) Relationship between prevalence threshold and the number of genes classified as core genes across 8,603 E. faecalis genomes. The curve demonstrates a characteristic L-shaped distribution, with a steep decline at low thresholds reflecting the large number of accessory genes present in only a subset of genomes, followed by a plateau in the mid-range thresholds representing the stable core genome. (B) Detailed view of the high-prevalence region (90-100%), highlighting the threshold sensitivity in this range. The red dashed lines indicate the 95% prevalence threshold used in this study, which identified 1,251 core genes. This threshold balances inclusivity of conserved genes while excluding strain-specific variants, and represents a commonly applied standard for bacterial core genome definition.
