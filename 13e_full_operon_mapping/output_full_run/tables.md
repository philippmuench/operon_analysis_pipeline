# Variant Site Output Tables

*Updated: 2026-01-07 with 8,596 genomes*

This directory contains summary tables generated by `analyze_updated_operon_variants.py`. The files capture allele usage across all assemblies mapped to the operon reference.

## `variant_site_summary.tsv`

Per-site roll-up of allele counts and percentages. See actual TSV file for current values (8,596 assemblies).

| Column | Description |
| --- | --- |
| `site` | Variant site identifier (e.g. `859`, `4652..4653`, `7501^7502`). |
| `origin` | Reference/origin allele defined in `FL_operon_with_SNPs.gb`. |
| `variant` | Annotated alternate allele for the site. |
| `total_calls` | Number of assemblies contributing data at this site (origin + variant + gap + missing + other). |
| `origin_count` | Assemblies matching the origin allele. |
| `origin_percent` | Percentage of assemblies matching the origin allele. |
| `variant_count` | Assemblies matching the variant allele. |
| `variant_percent` | Percentage of assemblies matching the variant allele. |
| `gap_count` | Assemblies with a deletion relative to the query at this position. |
| `gap_percent` | Percentage of assemblies with a deletion. |
| `missing_count` | Assemblies without coverage or alignment data at this site. |
| `missing_percent` | Percentage of assemblies lacking coverage. |
| `other_count` | Assemblies carrying alleles different from origin and variant. |
| `other_percent` | Percentage of assemblies carrying other alleles. |
| `other_breakdown` | Semicolon-delimited list of other alleles with counts and percentages (empty if none). |

## `variant_site_allele_counts.tsv`

Expanded list of all allele types observed per site. See actual TSV file for current values.

| Column | Description |
| --- | --- |
| `site` | Variant site identifier. |
| `allele` | Observed allele sequence or keyword (`missing`, `gap`). |
| `count` | Assemblies with this allele. |
| `percent` | Percentage of all assemblies reporting this allele at the site. |
| `category` | Category label (`origin`, `variant`, `missing`, `gap`, `other`). |
| `is_origin` | Boolean flag indicating `allele` equals the origin allele. |
| `is_variant` | Boolean flag indicating `allele` equals the variant allele. |

## `variant_site_calls.tsv`

Per-assembly per-site allele assignments. The full table is large (one row per assembly per site), so it remains available as TSV for downstream processing.

| Column | Description |
| --- | --- |
| `assembly` | BLAST result stem (TSV filename without extension). |
| `site` | Variant site identifier. |
| `allele` | Allele assigned for this assembly/site combination. |
| `category` | Category label (`origin`, `variant`, `missing`, `gap`, `other`). |
| `is_origin` | Boolean flag indicating the allele equals the origin allele. |
| `is_variant` | Boolean flag indicating the allele equals the variant allele. |
