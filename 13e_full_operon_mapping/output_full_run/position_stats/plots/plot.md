# Legacy Operon Variation Plots

- **legacy_mismatch_rate.png** — Line plot of per-site mismatch frequencies (percentage of assemblies carrying a nucleotide different from the legacy reference) along the full operon. Grey vertical spans mark gene annotations from the legacy GenBank file.
- **legacy_deletion_rate.png** — Line plot of per-site gap frequencies (percentage of assemblies with a deletion relative to the legacy reference) across the operon, with the same legacy gene annotations overlaid.

Both panels summarise the 8,210 legacy-reference BLAST alignments retained at ≥90% identity and ≥80% query coverage; rates are expressed as percentages of assemblies contributing coverage at each position.
