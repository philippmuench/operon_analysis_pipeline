# Legacy Operon Variation Plots

- **legacy_mismatch_rate.png** — Line plot of per-site mismatch frequencies (percentage of assemblies carrying a nucleotide different from the legacy reference) along the full operon. Grey vertical spans mark gene annotations from the legacy GenBank file.
- **legacy_deletion_rate.png** — Line plot of per-site gap frequencies (percentage of assemblies with a deletion relative to the legacy reference) across the operon, with the same legacy gene annotations overlaid.
- **legacy_coverage.png** — Coverage trace showing the percentage of assemblies aligned at each reference position, plotted with identical gene spans to highlight regions where alignments drop out entirely.

All three panels summarise the ~8,222 legacy-reference BLAST alignments retained at ≥90% identity and ≥80% query coverage (from 8,603 genomes); mismatch/deletion rates are reported for assemblies contributing coverage, while the coverage plot contextualises positions with little or no aligned support.
